# WikiResPublique

**Res Publique** — свободная энциклопедия конфы. Живёт на https://respublique.respubli.cc

Создан через Telegram-бота 2026-08-30.

## Что где лежит

| Что | Где | Переживает пересборку образа |
| --- | --- | --- |
| Движок (код, стили, шаблоны) | `server.js`, `src/`, `public/` | — пересобирается |
| База: страницы, правки, аккаунты | `data/wiki.sqlite` | да, каталог примонтирован снаружи |
| Картинки статей | `media/` | да, каталог примонтирован снаружи |
| Начальное наполнение | `seed.js` | создаёт только недостающие страницы |

Смысл разделения: код меняется пересборкой, а данные и картинки к образу не привязаны.
Раньше база лежала в анонимном docker-томе и пропала бы при первой же пересборке.

## Как запускается

Образ собирается из этого каталога, контейнер поднимается с двумя монтированиями:

* `data/` → `/data` (запись, там база; `DB_FILE=/data/wiki.sqlite`)
* `media/` → `/media` (чтение, там картинки; `MEDIA_DIR=/media`)

Подводный камень: пути монтирования у `docker_run` считаются от рабочего каталога
сессии, а не от корня проекта. Из сессии, работающей в `.tg-worktrees/<n>`, источники
надо писать как `../../data` и `../../media` — иначе база уедет во временный worktree
и исчезнет вместе с ним. Проверять после запуска: `wiki.sqlite` должен появиться
в `data/` в корне проекта.

Порт внутри контейнера — `20030`, наружу он опубликован как
https://respublique.respubli.cc

## Как добавить фотографию к статье

1. Положить файл в `media/`, имя — латиницей: `media/emili-zaifert.jpg`.
2. В карточке статьи (YAML-блок в самом верху) указать путь:
   `фото: /media/emili-zaifert.jpg`.
3. Всё. Пересобирать образ и перезапускать контейнер не нужно — каталог
   примонтирован, файл виден сразу.

В карточке понимаются ключи `фото` / `изображение` / `image`; путь должен быть либо
от корня сайта (`/media/...`), либо полным `https://`-адресом.

## Как добавить или поправить статью

Через сайт: зайти под своим аккаунтом и нажать «Править». Ничего пересобирать не нужно,
правки сразу в базе и видны в [свежих правках](https://respublique.respubli.cc/changes).

`seed.js` трогать стоит только ради базовых страниц: он выполняется при каждом старте
контейнера и создаёт лишь те страницы, которых в базе нет, — существующие он не перезаписывает.

## Локальный запуск

```sh
npm ci
npm run seed      # идемпотентно
npm start         # http://127.0.0.1:20020
```

Переменные: `PORT`, `DB_FILE` (по умолчанию `data/wiki.sqlite`), `MEDIA_DIR`
(по умолчанию `media/`), `INVITE_CODE` — код приглашения для регистрации.

## Аккаунты

Регистрация по коду приглашения. Первый зарегистрировавшийся живой участник
становится администратором; системный «Бот», от имени которого сделано начальное
наполнение, на эту роль не претендует.
